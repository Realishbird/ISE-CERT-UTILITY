Certificate and DNS

Let's Encrypt validates ownership with a DNS TXT record created through the Cloudflare API. The token needs Zone: DNS: Edit and Zone: Zone: Read on every zone that contains one of the certificate's names.

ISE connection

Uses the ISE OpenAPI certificate endpoints. Enable OpenAPI and use an account with the ERS Admin or Super Admin role.

ISE installs an imported certificate only on the node that receives the request, so each node is updated through its own API host, one at a time. The Primary Admin Node is updated last.

The EAP certificate is never changed. The utility records it before every import and stops if it changes afterwards.
